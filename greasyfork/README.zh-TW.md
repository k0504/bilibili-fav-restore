# Bilibili 收藏夾失效影片資訊還原

[简体中文](./README.zh-CN.md) | [**繁體中文**](./README.zh-TW.md)

還原 bilibili 網頁版收藏夾中失效影片（已刪除 / UP 自刪 / 政策下架）的原始封面、標題與作者資訊。

收藏夾裡的失效影片只剩灰色佔位圖和「已失效视频」幾個字。安裝本腳本後開啟收藏夾，這些影片會自動變回原來的封面和標題。

## 功能

- 自動還原失效影片的封面、標題、UP 主、播放數等資訊，還原過的卡片以刪除線和灰化標記
- 一鍵備份整個收藏夾到瀏覽器本機，影片日後失效時直接從本機還原，不依賴任何網站是否還留有資料
- 還原成功的結果自動存入本機備份，不會過期，可隨備份一併匯出
- 備份可匯出為 ZIP 檔案自行保管，也可重新匯入或遷移到其他瀏覽器
- 偵測被 bilibili 服務端直接丟棄、頁面上根本不顯示的影片，列出 av 號並附第三方存檔站連結
- 確認無法找回的影片可停止重試，不再反覆發起無意義的請求
- 頁內設定面板可調整掃描、重試、快取、備份等 32 項參數

## 首次使用

1. 安裝腳本後，開啟任意收藏夾頁面，例如 `https://space.bilibili.com/{UID}/favlist?fid={收藏夾 ID}`。
2. 點擊頁面右下角的圓形浮動按鈕，選擇 **账号与登录 → 登录（TV 端二维码）**。
3. 用 bilibili 手機客戶端掃碼並確認。僅官方客戶端可用，微信掃碼無效。
4. 重新整理頁面，失效影片即自動還原。

個別影片掃碼登入後仍無法還原時，可改用 **登录（手动输入凭据）** 貼上自行抓取的 Android 端 `access_key`。

## 日常使用

右下角的浮動按鈕是主入口，點擊展開選單，全部功能都在其中；卡片右上角的三點選單裡另有針對單一影片的操作（複製資訊、檢視封面、重試控制等）。腳本內部 UI 文字目前為簡體。

- **備份**：選單 → 备份 → 备份当前收藏夹。趁影片還有效時把資訊和封面圖存到本機；「管理备份」可瀏覽、匯出、刪除。
- **自動轉存**：還原成功的影片會自動存入同一份備份，無需手動操作，預設開啟。
- **停止重試**：確認已被永久刪除、怎麼重試都無結果的影片，用封面上的按鈕或三點選單停止重試。
- **設定**：選單最下方，修改即時生效。

各功能的完整說明見[使用手冊](https://github.com/k0504/bilibili-fav-restore/blob/main/docs/MANUAL.md)。

## 已知限制

- 僅支援本人收藏夾或公開收藏夾。
- 封面託管於 bilibili CDN，服務端已刪除檔案的無法還原；本機備份中存有封面的除外。
- 第三方存檔站（biliplus、jijidown）的可用性不受腳本控制。
- 備份保存在瀏覽器裡，更換瀏覽器或清除站台資料後即消失；長期保管請使用匯出功能。
- bilibili 接口簽名金鑰被官方輪換時（錯誤碼 `-3` / `-101` / `-663`），需等待新版本發布。
