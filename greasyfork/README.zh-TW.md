# Bilibili 收藏夾失效影片資訊還原

[简体中文](./README.zh-CN.md) | [**繁體中文**](./README.zh-TW.md)

還原 bilibili 網頁版收藏夾中失效（已刪除 / UP 自刪 / 政策下架）影片的原始封面、標題與作者資訊。同時偵測並展示 bilibili 服務端層面已經丟棄、不在常規接口回傳的條目，並附第三方歸檔站快照連結。

bilibili 網頁版收藏夾接口對失效條目僅回傳固定佔位封面與「已失效视频」文字。本腳本呼叫 bilibili Android 客戶端使用的接口（含正確簽名），從服務端取回失效前的 metadata 快照並替換頁面 DOM。此外提供本機備份功能，可在條目仍然有效時預先留存封面與資訊，日後失效時直接以本機資料還原，不依賴任何遠端是否仍保有該條目。

## 功能

- 還原失效條目的原始封面、標題、作者、播放數與彈幕數，並以刪除線與灰化標記區分已還原的卡片
- 頁內浮動按鈕：可拖曳定位，點擊展開二級選單，涵蓋腳本的全部指令
- 偵測 bilibili 服務端靜默丟棄的條目（API 實際回傳數小於聲明總數），列出對應 av 號並附 biliplus 、jijidown 三個第三方歸檔站的快照連結
- 在卡片三點選單中注入複製、還原與重試相關的操作
- 對確已刪除、反覆重試仍無結果的條目，支援逐條或整頁停止重試，避免每次進入收藏夾重跑同一輪取樣
- 備份目前收藏夾的 metadata 與封面圖本體至瀏覽器 IndexedDB，可匯出為 ZIP 檔案自行保管，也可將該檔案重新匯入以合併回 IndexedDB 或遷移至另一網域
- 提供 TV 端 QR Code 登入與手動貼上 `access_key` 兩種登入模式
- Metadata 本機快取（GM storage），減少對 bilibili API 的重複請求
- 頁內設定面板：掃描頁數上限、背景重試節奏、快取有效期、請求逾時、備份並行數等 31 項參數可調，第三方歸檔來源可單獨關閉，修改即時生效

## 首次使用

1. 安裝腳本後，開啟任意收藏夾頁面，例如 `https://space.bilibili.com/{UID}/favlist?fid={收藏夾 ID}`。
2. 點擊頁面右下角的浮動按鈕，選擇 **账号与登录 → 登录（TV 端二维码）**。
3. 使用 bilibili 手機客戶端掃描頁面上顯示的 QR Code 並在手機端確認登入。僅 bilibili 官方客戶端可用，微信掃碼或網頁掃碼無效。
4. 登入成功後 `access_key` 寫入 GM storage，有效期約 30 天。重新整理頁面後，失效條目應自動還原原始封面與標題。

若 TV 模式下仍有條目無法取回原始 metadata，可改用 **账号与登录 → 登录（手动输入凭据）**，貼上一份由 Android 主端應用簽發的 `access_key`。

未登入或已執行登出時，腳本不再發起任何還原相關的網路請求，僅以本機快取與備份還原可涵蓋的條目。

## 頁內操作入口

收藏夾頁面右下角常駐一枚圓形浮動按鈕，為腳本的主要入口。按住即可拖曳到順手的位置，該位置會被記住；點擊則展開選單。

選單分為兩級：一級為五個功能分類，點擊進入二級後，最上方一行為「返回」。按 Esc 鍵逐級返回，點擊選單以外的區域關閉。部分條目右側以淺色小字顯示目前狀態，例如登入模式、已停止重試的條目數，於選單展開時即時計算。

腳本內部 UI 文字目前為簡體，下表照實列出選單上顯示的字樣。

| 分類 | 條目 |
| ---- | ---- |
| 账号与登录 | 登录（TV 端二维码）、登录（手动输入凭据）、查看登录状态、注销 |
| 扫描与修复 | 立即重新扫描并修复、扫描静默丢弃的条目 |
| 重试控制 | 本页全部停止重试、清除所有「停止重试」标记 |
| 备份 | 备份当前收藏夹、管理备份、导入备份文件 |
| 维护与调试 | 开关调试日志、清除所有缓存并刷新页面 |
| 设置 | 直達項，無二級選單；開啟設定面板 |

同一組指令亦可在瀏覽器擴充功能圖示的腳本選單中找到，前綴為 `fav-fix：`，兩處行為完全一致。此外，收藏夾卡片右上角的三點選單中會注入複製 AV / BV 號、複製完整資訊、檢視原始封面、在 biliplus 檢視、清快取並重抓，以及停止或恢復該條目重試等操作，依卡片目前狀態顯示。

## 停止無謂的重試

bilibili 的 Android 端收藏接口並不穩定，同一收藏夾的失效條目在每次遍歷中會隨機遺漏一部分。腳本據此對未能立即還原的條目啟動背景重複取樣：連續七輪無新增即判定為無法取回並停止，全程約四分鐘。對於確實已被永久刪除的條目，該過程不會有任何結果，卻會在每次進入該收藏夾時重新執行一遍。

因此腳本提供兩層抑制機制：使用者顯式停止的記錄永久有效，直至顯式恢復；背景取樣自行放棄時寫入的記錄有效期為 7 天，到期後該條目恢復正常重試。

操作方式：

- **封面按鈕**：仍在重試的卡片，其封面正中央有一枚圓形按鈕，依目前狀態顯示停止圖示（方塊）或恢復圖示（循環箭頭），點擊即執行。封面左上角的小標籤僅指示狀態，不可點擊。
- **卡片三點選單**：提供「停止重试」與「恢复重试」，依卡片目前狀態互斥顯示。
- **本页全部停止重试**（選單 → 重试控制）：一次停止目前頁面上全部仍在重試的條目。
- **清除所有「停止重试」标记**（選單 → 重试控制）：清空全部停止記錄。該記錄以 av 號為鍵、不區分收藏夾，因此此項的範圍是所有收藏夾，而非目前頁面。

停止的對象是網路重試，不影響本機資料：已備份的條目仍會照常以本機備份還原，停止記錄亦不受「清除所有缓存」影響。

## 備份收藏夾到本機

還原流程屬於事後補救，能否取回不由腳本決定。備份功能與之相反，用於在條目仍然有效時預先留存。

選擇 **選單 → 备份 → 备份当前收藏夹**，腳本將逐頁遍歷目前收藏夾，把標題、簡介、UP 主、分區、時長、投稿與收藏時間等 metadata，以及封面圖的圖片本體，寫入瀏覽器的 IndexedDB。該收藏夾中的條目日後失效時，備份將作為優先級最高的資料來源參與還原：即使 bilibili CDN 已清除封面圖檔案，腳本也會改用備份中的圖片本體填入卡片封面。

備份可重複執行，封面網址未變化的條目僅更新 metadata、不重複下載圖片。任何清除快取的操作均不會刪除備份資料。

選擇 **選單 → 备份 → 管理备份** 可開啟頁內面板，瀏覽、搜尋、依收藏夾過濾、匯出或刪除已存備份。面板底部的「导出筛选结果」將目前篩選結果打包為一個 ZIP 檔案並交由瀏覽器下載，內含 `manifest.json`、`items.json` 與 `covers/` 目錄下的封面原始位元組，可自行長期保管。

若需要將先前匯出的 ZIP 檔案重新匯入，可在備份管理面板底部點擊「导入备份文件」，或經浮動按鈕選單的 **备份 → 导入备份文件**、Tampermonkey 擴充功能選單的 `fav-fix：导入备份文件` 開啟檔案選取對話框。匯入按條目合併到 IndexedDB 中既有的備份：備份時間較新者優先，所屬收藏夾取聯集，已存的封面不會被空值覆蓋，因此重複匯入同一份檔案不會產生變化。檔案解壓後以其他工具重新壓縮仍可正常匯入。該檔案同時可匯入到另一個網域（`space.bilibili.com` 與 `www.bilibili.com`）下執行的腳本，是在兩者獨立資料庫之間遷移備份的方式。

## 設定

浮動按鈕選單最下方的 **设置** 會開啟頁內設定面板，Tampermonkey 擴充功能選單中的 `fav-fix：设置` 與之等效。面板分為掃描與修復、背景重試、快取與標記、網路與資料來源、備份、介面與偵錯六個分頁，共 31 項參數：修復掃描的頁數上限、背景重試的放棄條件與間隔梯度、兩檔快取有效期、各類請求逾時與資料來源熔斷條件、備份的翻頁間隔與封面下載並行數、備份管理面板的每頁條數等，均可依需求調整；biliplus 與 jijidown 兩個第三方歸檔來源亦可單獨關閉，關閉後腳本不再向對應站點發送任何請求。

面板沒有「保存」按鈕：數值於失去焦點或按下 Enter 時提交，開關於點擊時提交，提交後立即生效，無需重新整理頁面。超出範圍的輸入會被拒絕並於欄位下方說明原因，輸入內容保留在原處以便修改。已修改的項目會在標題旁標註「已修改」並提供單項重設，面板底部另有依分組或全部恢復預設值的按鈕。

## 多語言支援

腳本 metadata 同時提供簡體（預設）與繁體（`@name:zh-TW` / `@description:zh-TW`）變體。Tampermonkey 會根據瀏覽器 `navigator.language` 自動挑選：`zh-TW` / `zh-HK` / `zh-MO` 命中繁體名稱，其他語系回退到簡體。腳本內部 UI 文字（按鈕、提示、tooltip）目前為簡體；若希望貢獻繁體 UI 翻譯，歡迎提交 Pull Request。

## 已知限制

- 僅支援本人收藏夾或公開收藏夾。私密收藏夾因 API 鑑權限制無法讀取。
- 腳本回傳的「原始封面」託管於 bilibili CDN，若 bilibili 在服務端清除該資源檔案，腳本無法還原，此前已執行備份的條目除外。
- 每頁 20 條，預設最多翻閱 50 頁（約 1000 條），可於設定面板中調整。
- 第三方歸檔源（biliplus、xbeibeix、jijidown）的可用性與命中率不在腳本控制範圍內。
- 若 bilibili 接口簽名金鑰被官方輪換（錯誤碼 `-3` / `-101` / `-663`），需等待新版本發布。
- 「停止重试」記錄、浮動按鈕位置與設定面板中的全部參數不在多個分頁之間即時同步，在一處修改後，其他已開啟的分頁需重新整理才會反映。
- 備份資料庫受瀏覽器同源政策約束，`space.bilibili.com` 與 `www.bilibili.com` 各自持有獨立的一份，需分別備份；不過匯出的 ZIP 檔案可重新匯入到任一網域，是兩者之間遷移備份的支援方式。備份亦不隨瀏覽器設定檔同步，更換瀏覽器或清除站台資料後不再存在；如需長期保管，請使用匯出功能。
