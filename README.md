# bilibili-fav-restore

在 bilibili 网页版收藏夹中，自动还原失效视频（已删除 / UP 自删）的封面、标题与作者信息。

收藏夹里的失效视频只剩灰色占位图和「已失效视频」几个字。安装本脚本后打开收藏夹，这些视频会自动变回原来的封面和标题。

## 功能

- 自动还原失效视频的封面、标题、UP 主、播放数等信息，还原过的卡片以删除线和灰化标记
- 一键备份整个收藏夹到浏览器本地，视频日后失效时直接从本地还原，不依赖任何网站是否还留有数据
- 还原成功的结果自动存入本地备份，不会过期，可随备份一并导出
- 备份可导出为 ZIP 文件自行保管，也可重新导入或迁移到其他浏览器
- 可检查备份的视频是否仍在收藏夹里，取消收藏后遗留的备份会被标出，并可按此筛选清理
- 检测被 bilibili 服务端直接丢弃、页面上根本不显示的视频，列出 av 号并附第三方存档站链接
- 确认无法找回的视频可停止重试，不再反复发起无意义的请求
- 页内设置面板可调整扫描、重试、缓存、备份等 32 项参数

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome、Edge、Firefox 均可）。
2. 选择以下任一入口，浏览器访问后 Tampermonkey 将弹出安装对话框：

   - **[从 Greasy Fork 安装](https://greasyfork.org/zh-TW/scripts/578965-bilibili-收藏夹失效视频还原)**（推荐）
   - **[从 GitHub Raw 安装](https://raw.githubusercontent.com/k0504/bilibili-fav-restore/main/dist/bilibili-fav-restore.user.js)**

3. 之后有新版本时，Tampermonkey 会自动提示更新。

## 首次登录

1. 打开任意收藏夹页面，例如 `https://space.bilibili.com/{UID}/favlist?fid={收藏夹 ID}`。
2. 点击页面右下角的圆形悬浮按钮，选择 **账号与登录 → 登录（TV 端二维码）**。
3. 用 bilibili 手机客户端扫码并确认。仅官方客户端可用，微信扫码无效。
4. 刷新页面，失效视频即自动还原。

个别视频扫码登录后仍无法还原时，可改用 **登录（手动输入凭据）** 粘贴自行抓取的 Android 端 `access_key`。

## 日常使用

右下角的圆形悬浮按钮是主入口，点击展开菜单，全部功能都在其中；卡片右上角的三点菜单里另有针对单个视频的操作（复制信息、查看封面、重试控制等）。

- **备份**：菜单 → 备份 → 备份当前收藏夹。趁视频还有效时把信息和封面图存到本地；「管理备份」可浏览、导出、删除。
- **自动转存**：还原成功的视频会自动存入同一份备份，无需手动操作，默认开启。
- **清理遗留备份**：管理备份面板底部的「检查是否仍在收藏夹」，标出已取消收藏、只剩备份的条目，再按状态筛选删除。
- **停止重试**：确认已被永久删除、怎么重试都无结果的视频，用封面上的按钮或三点菜单停止重试。
- **设置**：菜单最下方，修改即时生效。

各功能的完整说明见[使用手册](docs/MANUAL.md)。

## 已知限制

- 仅支持本人收藏夹或公开收藏夹。
- 封面托管于 bilibili CDN，服务端已删除文件的无法还原；本地备份中存有封面的除外。
- 第三方存档站（biliplus、jijidown）的可用性不受脚本控制。
- 备份保存在浏览器里，更换浏览器或清除站点数据后即消失；长期保管请使用导出功能。

完整列表见[使用手册](docs/MANUAL.md)的「已知限制」。
